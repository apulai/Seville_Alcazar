# Seville Alcázar – magyar Markdown, eredeti vizuális anyagokkal

A csomag a forrás-PDF magyarított Markdown-változatát és az eredeti PDF oldalairól kinyert vizuális anyagokat tartalmazza.

## Tartalom

- `real_alcazar_sevilla_magyar.md` – magyar Markdown
- `images/` – az eredeti PDF oldalainak nagy felbontású képei
- `oldalak-attekintese.jpg` – gyors áttekintő lap

## Fontos

Ahol a PDF összetett, több elemből álló oldalt tartalmaz, ott a teljes oldal képe szerepel, hogy ne vesszen el semmilyen eredeti vizuális információ. Ez különösen a térképekre, alaprajzokra és összetett feladatábrákra igaz.
